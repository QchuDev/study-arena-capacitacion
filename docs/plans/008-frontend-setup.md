# 008 - Setup Frontend (Vite + React + TypeScript)

## Estado: PENDIENTE

## Objetivo
Crear el proyecto frontend con Vite, instalar dependencias base y definir
la estructura de carpetas.

## Tareas
- [ ] Crear proyecto: `npm create vite@latest frontend -- --template react-ts`
- [ ] Instalar dependencias: axios, react-router-dom, @jitsi/react-sdk
- [ ] Instalar Tailwind CSS + shadcn/ui
- [ ] Crear estructura de carpetas (api, pages, components, contexts, hooks, types, services, routes, layouts, utils)
- [ ] Configurar `.env` con `VITE_API_URL`
- [ ] Configurar instancia Axios con baseURL e interceptor de auth
- [ ] Verificar que `npm run dev` funciona

## Dependencias
- Ninguna (puede hacerse en paralelo con el backend)

## Resultado esperado
Proyecto frontend que compila y sirve en localhost con la estructura lista para desarrollar.
